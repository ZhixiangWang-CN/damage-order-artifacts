# 补充方案 12：指令推力 + 答案余量能否预测脆度（预注册）

写于 2026-10-28，在任何留出模型的推力测量之前。用户当日批准设计并运行（"设计并跑起来实验吧"）。

## 坦白在先
- 假设来自探索性试点（PILOT_PUSH.md）：在 q7、llama 上试了几种量（推力、去指令对数概率、每 token 推力、带指令对数概率），挑出"推力 + 答案余量，z 分数相加"这一组合（无拟合 r 为 q7 0.78、llama 0.71）。试点看过这两个模型的观测脆度，所以它们不进入判定。
- 被预测的量（各测度的脆度指数，补充 8、9）早已存在并被看过；预测量（留出模型的推力）在本文件与分析脚本锁定之后才测量。答案余量（完好 CHOICE 分数）早已存在，它单独的预测力在补充 10 中已报告（格式之内 B2 0.80），不是新发现。
- 本批检验的是：在 6 个未看过的模型上，推力是否把格式次序排对、并在答案余量之外增加预测力。

## 假设
完好模型按要求的格式作答，需要指令把输出从模型的默认说法推开；损伤先削弱这股推力。格式需要的推力越大越先坏（格式项）；任务项由答案本身的余量决定。

## 测量（push.py，只在完好模型上运行，不施加损伤）
每个模型、16 个任务、BARE / JSON / TWICE 三个格式、300 道评测题：规范目标输出（atlas_full.target + 轮次结束 token）在两种提示下的求和对数概率：
- 有指令：chat(body(it, f))，即补充 8 所用提示；
- 无指令：chat(题干，选择题含选项)，去掉格式指令。
CHOICE 格式不适用（无生成指令），不进入本批。

## 预测（analyze13.py，无任何在受损数据上拟合的参数）
- push_m = 完好时判对的题上 (有指令 − 无指令) 的平均；至少 10 道判对题。
- margin_t = −(全部评测题上 CHOICE 正确候选分数 − 最高干扰项分数 的平均)。
- pred_m = z(push) + z(margin)，z 在该模型参与分析的测度内计算。
- 观测：四种随机损伤（noise、zero、neuron、ld_rand）中拟合出该测度的 log n 的平均，至少两种（与 analyze11.observed 相同；数据 analysis10_out/analysis10_8models.json）。

## 模型
- 留出（进入判定）：q15、phi、mis、gemma、q14、q32。
- 试点（只报告，不进入判定）：q7、llama。

## 检验与判定（写在测量之前）
- **P1**：每个留出模型内 pred 与观测 log n 的 Pearson 相关；6 个模型的中位数。
- **P2**：推力的格式均值次序与观测格式均值次序完全一致的模型数。
- **P3**：pred 的相关高于只用答案余量的相关的模型数（推力在答案余量之外是否有增量）。
- **判定**
  - **押（两部分解释进入正文主线）**：P1 ≥ 0.80，且 P2 ≥ 5/6，且 P3 ≥ 5/6。
  - **部分成立（写成部分的两部分解释）**：P1 ≥ 0.65，且 P2 ≥ 4/6，且 P3 ≥ 4/6。
  - **停（推力在附录报告为否定结果）**：其余情形。
- **描述（不进入判定，全部报告）**：推力单独的相关；把推力换成其格式均值（纯粹的格式间标签）后的相关；格式之内推力与观测的相关。试点中格式均值版本的相关反而更高（q7 0.86、llama 0.73），说明推力的预测力主要在格式之间，格式之内的逐题变化基本是噪声；结果按此如实表述。

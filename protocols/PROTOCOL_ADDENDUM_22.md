## 方法（analyze26.py）
- 从原始运行文件（runs_v8、runs_v9，与 analysis15 相同的文件）取逐题 correct、format_ok、content_any → analysis26_cache.pkl。
- 生成格式（BARE、JSON、TWICE）的四种评分；CHOICE 在各评分下不变：
  - strict：论文现用评分（模板对且答案对），机会率 1/k（列选项与是否题）否则 0。
  - strict0：同样的正确性，但所有生成量机会率设为 0。
  - content：评分器随运行写下的 content_any（不管模板，输出中有正确答案；选项与是否题取第一个独立字母或 yes/no，其他任务匹配任意位置的数字或名称），机会率同 strict。
  - template：只看 format_ok，机会率 0（只报告）。
- 可用量：原 usable 列表中完好时高于机会 0.05 的量（随评分不同而不同）。指数按正文方法（rank1，窗口 0.03–0.97，≥12 个量）。
- C1 共享顺序：每个模型内，七种损伤两两的任务效应 Pearson（≥8 个共同任务），取全部配对的中位数。
- C2 生成先于选择：随机损伤平均格式效应 CHOICE < BARE 的模型数。
- C3 压缩顺序：压缩对数指数与随机损伤参照（≥2 种随机损伤的对数平均）的 Pearson（≥10 个共同量），取模型 × 压缩格子中位数。
- C4 准确率：analyze19 预测器（随机损伤画像对一视同仁，留一量）。

## 检验与判定（content 与 strict0 各自判）
- C1 中位数 ≥ 0.70；C2 至少 7/8 个模型 CHOICE < BARE；C3 中位数 ≥ 0.70；C4 三种压缩方法都满足下降中位数 ≥ 25% 且更准格子 ≥ 75%。
- 一种评分四项全过 → 该评分下主要结论成立。两种评分都成立 → 押；一种 → 部分；都不成立 → 停。
- 只报告：template 评分下的 C1–C4；各评分的平均格式效应（JSON、TWICE 的格式代价中有多少在 content 评分下消失，即属于模板）；有信息条件下，完好时答对、损伤后答错的题中模板失败所占比例与平均模板有效率。
- 写法：押 → 正文与方法写"主要结论在只看内容、以及机会率设为 0 时都成立"，并报告格式代价中模板与内容各占多少；不过 → 如实写哪一项在哪种评分下失败。
